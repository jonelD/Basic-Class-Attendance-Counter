# Student Attendance App

A simple Student Attendance App built while reviewing JavaScript fundamentals.

## About

This project is based on the Scrimba Passenger Counter lesson, but I modified it into a Student Attendance App to practice applying what I learned instead of only following the tutorial.

I am currently refreshing my JavaScript fundamentals and documenting my progress by creating small projects after each lesson.

## Features

- Increase student attendance count
- Reset attendance counter
- Clean and simple interface

## Technologies Used

- HTML
- CSS
- JavaScript

- Event handling
- Updating webpage elements with JavaScript
